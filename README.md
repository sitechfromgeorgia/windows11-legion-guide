# Windows 11 Pro setup guide (Lenovo Legion Pro 7 16IAX10H, 83F50025RK)

Single-file, offline-friendly Georgian guide for a clean Windows 11 Pro 26H2 install:
USB creation (Rufus), BIOS checks, install walkthrough, OOBE, drivers (NVIDIA Studio),
debloat options, legal activation paths, and the architecture/design software stack with
student licensing links.

Open `index.html` locally or use the GitHub Pages link.
